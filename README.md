# BookStack


## This Project Running on

- Oracle OpenJDK 19

## Name

Library Management System

## Description

Benutzerverwaltung: Unser System ist in der Lage, Informationen über Bibliotheks-Mitglieder zu speichern. Dazu zählen Vor - und Nachname, Username und das Passwort. Des Weiteren bietet es die Möglichkeit, Benutzerkonten anzulegen, zu aktualisieren und zu löschen. 

Medienverwaltung: Es ist möglich, Informationen über die verfügbaren Medien in der Bibliothek zu speichern und zu verwalten. Dazu gehören Bücher, Filme und bei Bedarf noch weitere Medien. Über Textfelder, können Informationen wie ISBN, Titel, Autor und Verfügbarkeitsstatus erfasst und in einer Datenbank gespeichert werden. Des Weiteren wurden Funktionen zur Aufnahme neuer Medien, Aktualisierung von Informationen und Entfernung von veralteten oder beschädigten Medien implementiert. 

Ausleih- und Rückgabeverwaltung: Das LMS bietet Unterstützung bei der Verwaltung von Ausleih- und Rückgabevorgängen. Bei der Rückgabe eines Mediums, aktuallisiert das System den Verfügbarkeitsstatus.

Benutzerfreundliche Oberfläche: Unsere GUI wurde so gestalten, dass eine einfache Navigation durch das System möglich ist. Benutzer sollten in der Lage sein, sich leicht anzumelden und auf die verschiedenen Funktionen des LMS zuzugreifen. Die Darstellung der Informationen wurde übersichtlich gehalten, mit Verwendung von klaren Beschriftungen und Symbolen.
